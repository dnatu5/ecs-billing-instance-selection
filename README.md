## 实例规格、镜像和存储：按用途挑，别只盯着核数

实例规格决定的是一整组属性：vCPU、内存、GPU、本地盘、物理网卡、网络带宽和PPS、云盘IOPS。选型思路按用途走：

- 网站和小型应用：通用型，vCPU与内存配比均衡，多数博客和企业站2核4G就够用
- 数据库、缓存等吃内存的应用：内存型
- AI训练推理、图形渲染：GPU型
- 大数据分析：大数据型或本地SSD型。本地盘性能高，但只配备在部分规格上，且只能做数据盘

镜像方面，公共镜像覆盖Windows Server和主流Linux，直接选就能用；已经有配好的环境，可以做成自定义镜像，避免每次重复配置；云市场里还有预装运行环境的镜像，建站、应用开发可以直接挑现成的。

存储记住两点：实例必须有系统盘，启动时靠它完成操作系统安装；业务数据放数据盘，容量不够可以扩容云盘或再挂盘。云盘有三副本技术保障，本地盘没有——用本地盘就得自己在应用层做数据冗余。

地域是这一步真正容易出事的地方：**实例一旦创建，地域就无法更换**。后面如果要跟阿里云的RDS云数据库走内网互通，数据库和ECS必须处在同一地域。所以下单前先想清楚用户位置、要不要和其他云产品组网，再去查对应地域的规格库存：👉 [查询各地域在售实例规格与库存](https://ecs-buy.aliyun.com/instanceTypes/?userCode=5eqf8rny#/instanceTypeByRegion)

## 只写在条款和帮助文档里的几件事

下面这些内容官网首页基本不提，但都直接影响使用和账单。

1. 退款停机后，资源保留时间不一样。包年包月实例申请退款停机后，vCPU、内存、固定公网IP、快照最长24小时内释放，云盘最长保留15天——官方还注明这是最长时间，实际释放可能提前。退款前先把数据导出来。

2. 到期和欠费都有“回收”环节。包年包月到期后先进入“已过期”状态，随时可能进入“过期回收中”；按量付费欠费停机后同理，随时可能进入“欠费回收中”。这两个状态之后就是释放，续费要赶在到期前。

3. 有些操作必须先停机：更换操作系统、修改私有IP、按量付费实例变配规格。另外，实例重启后可能被调度到其他宿主机，如果业务要求固定宿主机，需要购买专有云宿主机并启用关联宿主机。

4. Running状态不代表系统能连上。实例Running相当于电脑开了机，操作系统不一定已经运行完成。SSH或RDP连不上时，先查实例健康状态，别急着怀疑配置出错。

5. 免费的安全能力别浪费：安全组免费，用来控制出入网规则和端口监听；DDoS基础防护默认开启，提供不超过5Gbps的防护；基础安全服务免费，包含异常登录检测、漏洞扫描、基线配置核查。更高的防护等级才需要单独购买。

6. 怕误释放可以开释放保护。实例释放后，实例ID、固定公网IP、系统盘、设置随实例释放的数据盘都不可恢复；EIP和设置不随实例释放的数据盘会解绑保留。这个开关点一下就行。

## 常见问题

**ECS实例创建后还能换地域吗？**
不能。实例创建成功后元数据就固定下来，无法更换地域，所以地域选择必须放在创建之前。

**按量付费实例停机后还收费吗？**
默认模式会继续收费。启用节省停机模式后，vCPU、内存和固定公网IP停止计费，但云盘、EIP等资源保留并继续收费。

**云盘上的数据会丢吗？**
云盘采用三副本技术，官方标注数据可靠性99.9999999%，但备份仍要自己做，官方的建议是用快照备份云盘数据；本地盘没有多副本，需要自行在应用层做冗余。

**包年包月到期后数据马上就没了吗？**
不会马上没。到期后实例先进入“已过期”状态，随后随时可能进入“过期回收中”，之后才释放，不同状态下资源保留情况不同。确定不续费的话，主动把云盘数据下载或迁移走最稳妥。

**必须用控制台买吗？**
不用。控制台最直观，也可以走API/SDK、资源编排ROS、Terraform、系统运维管理OOS等途径。通过控制台或RunInstances创建的实例会自动启动，不需要手动点启动。
